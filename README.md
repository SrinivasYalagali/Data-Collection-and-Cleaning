# Data Collection and Cleaning

## Project Overview
This project demonstrates the complete data collection and data cleaning process using the Titanic dataset. The dataset was loaded directly from the Seaborn library and cleaned using Python.

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Titanic Dataset loaded using:

```python
sns.load_dataset("titanic")
```

## Project Workflow
- Data Collection
- Data Inspection
- Missing Value Analysis
- Data Cleaning
- Outlier Detection
- Outlier Handling
- Standardization
- Normalization
- Final Dataset Validation
